FolderMap 

用途：扫描本地文件夹，生成可直接发给网页端 AI 的“文件目录与文件信息”。
软件不会把原文件发送给 AI；导出的只是文件夹层级、文件名，以及按需勾选的路径、大小、修改时间等信息。

使用：
1. 双击 run_windows.bat。
2. 点击“选择文件夹”选择要扫描的根目录。
3. 按需设置过滤规则：
   - “常见目录”下拉：可快捷加入 .git、node_modules、build、dist 等常见无关目录。
   - “加入忽略”：会弹出当前扫描目录的文件夹树，可用 Ctrl / Shift 一次多选多个具体文件夹后加入忽略。
   - 手写忽略目录：仍然支持逗号分隔输入。
   - 忽略后缀：可手写，也可从常见后缀下拉快速加入。
4. 点击“开始扫描”并查看目录预览。
5. 调整导出设置后点击顶部“导出文件”。默认格式为 Word (.docx)。

说明：
- 从“加入忽略”弹窗中选择的文件夹按具体相对路径过滤，例如 ./项目A/cache，只忽略这一处，不会误伤 ./项目B/cache。
- 常见目录按目录名过滤，例如 node_modules 会忽略扫描范围内所有同名目录。
- 页面保持单页布局；960×700 最小窗口下功能完整可见。
- 整页不滚动，只有目录预览区域内部滚动。
- 不调用任何 AI API，不上传任何本地文件。
